# Shipaton Submission Checklist

## Product evidence

- [x] Android debug build succeeds.
- [x] Unit tests and lint pass.
- [x] Rewind creates a real alternate branch.
- [x] Full local device flow reaches the coaching report.
- [x] RevenueCat purchase and restore code is implemented.
- [x] Release build rejects missing or Test Store RevenueCat keys.
- [x] AI service code, tests, validation, and rate limiting exist.
- [ ] Cloudflare Worker is deployed and live responses are device-tested.
- [ ] RevenueCat Offering returns a localized price on device.
- [ ] Test Store purchase activates the `pro` entitlement.
- [ ] Restore is tested with an existing purchase.

## Public artifacts

- [ ] Public MIT repository; verify from a signed-out browser.
- [ ] Repository default branch passes Android and backend CI.
- [ ] 1024 x 1024 project icon.
- [ ] At least one 1179 x 2556 no-frame screenshot.
- [ ] Public demo video under two minutes; verify signed out.
- [ ] Hosted privacy policy.

## Devpost audit

- [ ] Title, tagline, description, categories, built-with tags, and links are complete.
- [ ] Existing partial draft is compared field by field before overwriting anything.
- [ ] No claims of users, revenue, conversion, testimonials, store availability, or integrations without evidence.
- [ ] RevenueCat implementation is visible in the video and described accurately.
- [ ] Career Coaching story explicitly covers realistic practice, useful feedback, and confidence building.
- [ ] Next Gen public source and license requirements are satisfied.
- [ ] Final preview has no placeholders, broken links, private videos, or inaccessible repository.
- [ ] Submission confirmation is captured after the final save/submit action.

## Grand Prize gate

- [ ] Publicly downloadable eligible store build exists in the United States.
- [ ] Real RevenueCat revenue exists during the submission period.
- [ ] Release and growth evidence is dated and reproducible.

If any Grand Prize item remains unchecked, omit those claims and maximize the reliable Career Coaching and Next Gen submission instead.
